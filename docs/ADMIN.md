# 어드민 사용법

## 열기

1. 프로젝트 폴더의 **`어드민 열기.bat`** 더블클릭
   (처음 한 번은 설치 때문에 1~2분 걸린다)
2. 브라우저에 어드민이 자동으로 열린다: `http://localhost:4321/admin`
3. 검은 창(명령 프롬프트)을 닫으면 어드민도 꺼진다. 작업 중에는 켜 둘 것.

> 어드민은 **내 컴퓨터에서만** 열린다. 공개 사이트에는 어드민이 없다.

## 화면 구성

- **왼쪽**: 편집할 항목(탭). 저장 안 한 탭에는 노란 점이 붙는다.
- **가운데**: 입력 양식. `*` 표시는 필수 칸.
- **오른쪽**: 사이트 미리보기. 저장하면 자동 새로고침. `모바일` 버튼으로 휴대폰 화면 확인.
- **왼쪽 아래**: GitHub에 올리기.

## 기본 흐름

1. 고친다
2. **저장** (또는 `Ctrl + S`) → 미리보기에서 확인
3. 다 됐으면 **GitHub에 올리기** → 1~2분 뒤 공개 사이트 반영

저장에 실패하면 위쪽에 이유가 나오고 문제 칸이 빨갛게 표시된다. 고치고 다시 저장.
잘못 고쳤으면 **되돌리기**(마지막 저장 상태로).

## 자주 하는 작업

### 선수 사진 넣기
`선수 · 스태프` → 선수 카드 펼치기 → 사진 칸에 파일을 끌어다 놓기 → 저장
- **사진 1 (정면)**: 선수 카드, 팬 투표, 메인 화면 스태프 줄
- **사진 2 (45도)**: 선수 팝업. 비워두면 사진 1이 쓰인다
- 원본을 그대로 올려도 된다(자동으로 줄여서 저장). 카드는 촬영 비율(2:3) 그대로 나온다.
- 동그란 얼굴 사진이나 투표 썸네일에서 얼굴이 잘리면 `얼굴 위치 (%)` 조절 (0 = 사진 맨 위).

### 화면 문구 바꾸기
`화면 문구` 탭에 사이트의 고정 글자가 전부 있다: 메뉴 이름, 섹션 제목(선수단·최근 경기…), 포지션 이름(탑·원거리 딜러…), 버튼(중계 채널…), 투표 안내, 팝업 항목 이름, 하단 문구.
- 칸을 비우고 저장하면 원래 문구로 돌아간다.
- 라이엇 고지문의 `{team}` 자리에는 팀명이 자동으로 들어간다.

### 선수 이름·닉네임 바꾸기
`선수 · 스태프` → 카드 펼치기 → 닉네임/실명 수정 → 저장
- 사람마다 내부 코드(top, jungle … analyst)가 자동으로 붙어 있다. 팝업 주소(`#p-top`)와 팬 투표 연결에만 쓰이고 어드민에는 보이지 않는다. 실제 게임 ID와는 무관하며 검색·외부 링크에 쓰이지 않는다.
- `사이트에 표시`를 끄면 그 사람이 사이트 전체에서 사라진다(목록에 빨간 「사이트에 안 보임」 표시).

### 로고 바꾸기
`팀 정보 › 로고`에 **배경이 투명한 PNG 또는 SVG**를 올린다. 로고 모양대로 글자색이 칠해져서, 영상 위에서는 흰색·스크롤 후에는 테마 글자색으로 자동으로 바뀐다. (흰 배경이 있는 JPG는 네모로 보이니 투명 배경으로 저장해서 올릴 것)

### 팀명 바꾸기
`팀 정보` → 팀명(영문)·약칭 → 저장. 메인 화면 아래쪽 팀명, 상단 로고 글자, 일정의 약칭까지 한 번에 바뀐다.

### 경기 결과 입력
`경기` → 해당 경기 펼치기 → 상태 `종료` → 우리 세트 / 상대 세트 입력 → 저장
- 새 경기: 맨 아래 `+ 항목 추가`. 일시는 한국 시간.
- `날짜순 정렬` 버튼으로 정리할 수 있다(사이트에는 어차피 날짜순으로 나온다).
- 시즌 순위·승패는 `팀 정보 › 시즌 기록`에서 따로 입력한다(자동 계산 아님).

### 팬 MVP 투표 열기 (가짜 집계)
`경기` → 끝난 경기 펼치기 → `팬 MVP 투표`
- `MVP 투표 열기` 체크
- `득표` → `+ 추가`로 선수별 기본 득표 입력
- `자연 증가`를 켜면 경기 후 72시간 동안 숫자가 조금씩 늘어난다(모든 방문자에게 같은 숫자)
- 사이트에는 투표가 열린 **가장 최근 경기** 하나만 나온다.

### 상단 공지 띠
`팀 정보 › 공지 띠` → 표시 체크, 문구·링크 입력. 링크에 `#schedule` 처럼 쓰면 페이지 안의 섹션으로 이동.

### 섹션 숨기기
`팀 정보 › 섹션 표시`에서 체크 해제.

### 메인 배너 영상 넣기
`메인 배너` → 항목 펼치기 → `영상 (mp4)`에 영상 파일을 끌어다 놓기 → 저장
- 소리 없이 자동 재생되고, 영상이 끝나면 다음 배너로 넘어간다. 배너가 하나면 반복 재생.
- `이미지` 칸에는 영상 첫 장면 캡처를 넣어두면 로딩 중에도 빈 화면이 안 보인다.
- **용량**: 20MB 이하 권장. 100MB가 넘으면 GitHub에 못 올린다. (1080p · H.264 · 15~30초면 보통 10~20MB)
- 영상은 `영상 한 번에 보여줄 시간`(기본 10초)만큼 재생하고 다음 배너로 넘어간다. 다시 차례가 오면 멈춘 곳부터 이어서 재생(끝까지 가면 처음부터). 0으로 두면 끝까지 재생.
- 사진 배너는 6초씩 천천히 확대되며 넘어간다.
- 순서는 ↑ ↓ 버튼. 예) 영상 → 단체사진 3장 → 영상(이어서) → …
- 배너가 화면 밖으로 스크롤되면 영상은 자동으로 멈춘다.

### 다크 / 라이트
`팀 정보 › 색 › 기본 테마`. 방문자는 사이트 오른쪽 위 달/해 버튼으로 바꿀 수 있다.

## GitHub에 올리기

- 처음에는 GitHub 저장소 연결이 필요하다(한 번만, 개발 쪽에서 설정).
- 연결 전에는 왼쪽 아래에 "GitHub 저장소가 아직 연결되지 않았습니다"가 나오고, 저장은 내 컴퓨터에만 된다.
- 올리기 창에 뜨는 파일 목록 = 이번에 공개되는 변경.

## 문제가 생기면

| 증상 | 해결 |
|---|---|
| 어드민 주소가 안 열림 | 검은 창이 켜져 있는지 확인. 꺼졌으면 `어드민 열기.bat` 다시 실행 |
| 미리보기가 안 바뀜 | 미리보기 위 `새 창 ↗`으로 열어 새로고침 |
| 올리기 실패 | 오류 문구를 그대로 복사해서 전달 |
