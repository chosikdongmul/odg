## 3. 어떻게 돌아가나 (오해 방지)

```
[내 컴퓨터]                                            [인터넷]
 어드민 열기.bat 더블클릭
   └ localhost:4321/admin  ── 저장 ──▶ src/data/*.json (프로젝트 폴더)
                                         │  오른쪽 미리보기 즉시 새로고침
                                         │
                        "GitHub에 올리기" ▼
                                    GitHub 저장소 ──(자동 빌드 1~2분)──▶ 공개 사이트
```

- **저장**은 내 컴퓨터의 파일만 바꾼다. 다른 사람은 아직 못 본다.
- **GitHub에 올리기**를 눌러야 공개 사이트에 반영된다. (1~2분 걸림)
- **어드민은 공개 사이트에 존재하지 않는다.** 빌드 결과물에 포함되지 않음을 확인했다. 비밀번호가 필요 없는 이유.
- 잘못된 값(빈 필수 칸, 없는 사진 등)은 **저장 단계에서 거부**되고 빨간 칸으로 표시된다. 깨진 사이트가 올라가지 않는다.
- 저장소는 공개다. 어드민으로 올린 사진·글은 GitHub에서 누구나 볼 수 있다.
- 팬 투표는 기기마다 1표를 기억할 뿐 서버 집계가 아니다. 숫자는 어드민 값 + 시간 경과로 계산되어 모든 방문자에게 같게 보인다.

## 4. 디자인 원칙 (v2 — ODOD 문법)

| 원칙 | 구현 |
|---|---|
| 한 가지 바탕 | 섹션마다 흑백을 뒤집지 않는다. 다크(기본)/라이트 중 하나로 쭉 |
| 선으로 구분 | 1px 선 + 한 단계 밝은 면. 지그재그·사선·찢어진 경계 없음 |
| 포인트색은 조금만 | 섹션 라벨, 라인 마크, 승리 표시, 진행 막대 정도 |
| 사진 판 | 선수 사진은 호리존색 판 위에 올려 흰 배경이 판에 녹게. 다크 테마에서도 사진은 밝은 판 |
| 모션 최소 | 배너 전환(페이드), 사진 살짝 확대 정도. 번쩍임·스크롤 등장 효과 없음 |
| 서체 | 영문 Archivo(정자, 굵게) / 한글 Pretendard |

실제 사진이 들어오면 확인할 것: 호리존 그림자가 보이는지, 얼굴 위치(카드 크롭), 흰 옷이 바탕에 묻히는지.

## 6. 폴더 구조

```
프로게임단/
├─ 어드민 열기.bat            ← 더블클릭하면 어드민이 열린다
├─ docs/  PLAN.md(이 문서) · ADMIN.md(어드민 사용법)
├─ admin/                     ← 어드민 화면 (배포 안 됨)
├─ integrations/local-admin.mjs  ← 어드민 서버 (저장·업로드·GitHub, 배포 안 됨)
├─ src/
│  ├─ data/*.json             ← 사이트 내용 전부. 어드민이 고치는 곳
│  ├─ assets/uploads/         ← 어드민으로 올린 사진 (긴 변 2800px로 줄여 저장)
│  ├─ lib/schema.ts           ← 내용 형식 정의 = 어드민 입력 양식
│  ├─ components/ · layouts/ · pages/ · styles/
├─ public/media/              ← 메인 배너 영상
├─ public/downloads/          ← 미디어 킷 파일
├─ _inbox/                    ← 원본 사진 보관용 (git 제외)
└─ .github/workflows/deploy.yml  ← GitHub에 올리면 자동 빌드·배포
```

## 7. 알고 있는 제약

- 프로젝트가 OneDrive 안에 있어 `node_modules`(수천 개 파일)가 동기화된다. 느려지면 폴더를 OneDrive 밖으로 옮기는 것을 권장.
- 챔피언 아이콘·한글 이름은 Riot Data Dragon에서 가져온다. 버전은 어드민 `팀 정보 › 챔피언 이미지 버전`.
- LCK·Riot 공식 로고는 쓰지 않는다. 푸터에 라이엇 고지문과 창작물 고지문이 있다(고지문은 어드민에서 수정 가능).
